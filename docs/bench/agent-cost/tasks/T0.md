Build the website described below in this folder, using the tools that are installed. `data.json` holds the data and `style.css` is the stylesheet to use as is.

- The home page `/` has the title "Demo — dividend stocks", a heading "Stocks (cycle <cycle_id>)" and a list of every stock in data.json, in order: its name as a link to its page, then " — " and its sector.
- Each stock has a page at `/stocks/<TICKER>/` (the ticker exactly as written in data.json) with the title "<name> (<TICKER>)". It shows the name with the ticker, the sector, and either the upcoming dividend as "Next dividend: <amount> <currency> — ex <ex_date>" or, when `upcoming` is null, "No upcoming dividend declared." When the upcoming dividend is not confirmed (`confirmed: false`) the page also shows a badge, an element with class `badge`, reading "Estimated — not yet declared". Each stock page links back to `/`.
- Every page loads `/style.css`.
- `/sitemap.xml` and `/robots.txt` as the requirements say; every page also has `og:type` "website".
- `<html lang="en">` on every page.
