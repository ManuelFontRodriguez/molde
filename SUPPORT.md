# Getting help

molde has one maintainer. I read everything and usually reply within a few days.

- **A question** (how do I…, does molde…): start a
  [discussion](https://github.com/ManuelFontRodriguez/molde/discussions) in Q&A. Check
  [docs/reference.md](docs/reference.md) first: it describes the site format, every
  check and every template filter.
- **A bug**, or a check that fails a correct site: open an
  [issue](https://github.com/ManuelFontRodriguez/molde/issues/new/choose). The smallest
  site that shows the problem makes it much faster to fix. `molde --version` tells me
  which build you have.
- **A security problem**: report it privately, as [SECURITY.md](SECURITY.md) explains.
- **An idea** for a capability: start a discussion in Ideas, or open a feature request.

Pull requests are welcome after an issue or discussion has agreed on the change; see
[CONTRIBUTING.md](CONTRIBUTING.md).
